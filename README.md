# Haoyang Wu — personal website

Single-page academic website built with [al-folio](https://github.com/alshedivat/al-folio) and deployed through GitHub Pages.

## Local development

```bash
bundle install
npm ci
bundle exec jekyll serve
```

Open `http://127.0.0.1:4000/`.

## Content

- Homepage: `_pages/about.md`
- Publications: `_bibliography/papers.bib`
- Social links: `_data/socials.yml`
- Profile and publication images: `assets/img/`
- Résumé: `assets/pdf/Resume_Haoyang_Wu.pdf`
